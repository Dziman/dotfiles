#+TITLE: Emacs cheat sheet: code buffers and Swift
#+STARTUP: overview

Keys as configured in =.emacs-dziman/configs/=. Stock Emacs keys are listed
only where they matter for code. Swift setup details: [[file:emacs-swift.md]].

** Project setup
| File in project    | Effect                                                                                                                              |
|--------------------+-------------------------------------------------------------------------------------------------------------------------------------|
| =.swiftformat=     | SwiftFormat; saving formats                                                                                                         |
| =.swift-format=    | Apple swift-format; saving formats                                                                                                  |
| (neither)          | =M-p f= uses Apple swift-format; saving does not                                                                                    |
| =.swiftlint.yml=   | SwiftLint runs, from the topmost config                                                                                             |
| =buildServer.json= | language server uses Xcode build settings                                                                                           |
| =.dir-locals.el=   | =((swift-mode . ((dziman/swift-platform . ios))))= checks a package against iOS; also =tvos=, =watchos=, =visionos=. Then =C-. h p= |

Create =buildServer.json= once per Xcode app, again after switching scheme, then build once in Xcode:
#+begin_src bash
xcode-build-server config -scheme <name> -project <file>.xcodeproj   # or -workspace <file>.xcworkspace
#+end_src
